# Automated File Organizer

This Python script automatically sorts and organizes files in a specified directory into categorized folders based on their file type.

## Features
- Moves documents, images, music, videos, and more into appropriate folders
- Helps keep directories clean and organized
- Easy to use with simple input

## How to Use
1. Run the script.
2. Enter the full path of the directory you want to organize.

## Requirements
- Python 3.x

## Example
If your folder contains:
- `song.mp3`
- `image.png`
- `document.pdf`

They will be moved to:
- `Music/song.mp3`
- `Pictures/image.png`
- `Documents/document.pdf`
